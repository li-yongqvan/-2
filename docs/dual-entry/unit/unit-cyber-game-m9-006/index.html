决策结论

C. 拖拽结束提交

实现最简单，避免渲染与引擎状态频繁同步。

选项对比

  • A. 渲染层先更新 — 响应最快，但渲染与引擎短暂不同步
  • B. 引擎层先更新 — 架构最一致，但可能粘滞
  • C. 拖拽结束提交 — renderer 维护拖拽偏移量，pointerup 时一次性提交最终位置并触发 rebuild。最简单
